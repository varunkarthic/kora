# Get started

KORA builds without a GPU. You need a Vulkan loader and driver only to run work on a device.

<div class="grid cards" markdown>

-   :material-download:{ .lg .middle } __[Install](installation.md)__

    ---

    Add the Rust crate, build `libkora` for C, or install the Python wheel. Check your devices with
    `kora-info`.

-   :material-rocket-launch:{ .lg .middle } __[Your first dispatch](quickstart.md)__

    ---

    Run the vector-add example in Rust, C, or Python and read back verified results.

-   :material-lightbulb-on-outline:{ .lg .middle } __[Core concepts](concepts.md)__

    ---

    Runtimes, devices, buffers and their replicas, kernels and manifests, events, and where bytes
    move.
